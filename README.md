# Vani Tuition Centre System – Research Repository

## Purpose

This repository contains all research and analysis materials used for the Vani Tuition Centre Admin Portal and Website System.

The repository supports the requirement gathering and analysis phases of the System Design Project.

---

## Repository Structure

```plaintext
research/
│
├── Literature-Review/
├── Competitive-Analysis/
├── Client-Interviews/
└── References/
```

---

## Included Materials

- Literature review notes
- Competitive analysis reports
- Client interview transcripts
- Requirement gathering notes
- Research references and articles

---

## Tools Required

- Microsoft Word / Google Docs
- Spreadsheet Software
- PDF Reader
- Internet Browser

---

## Branch Strategy

| Branch | Purpose |
|--------|---------|
| `main` | Approved research materials |
| `draft/<research-topic>` | Ongoing research branches |
| `fix/<issue-number>` | Corrections and updates |

---

## Contribution Guidelines

All team members must:

- Follow repository branching rules
- Use meaningful commit messages
- Verify research sources before submission
- Create Pull Requests for all changes

Please read `CONTRIBUTING.md` before contributing.

---

## Team Workflow

1. Pull latest repository changes
2. Create a research draft branch
3. Add or update research materials
4. Commit changes properly
5. Push the branch
6. Create a Pull Request
7. Obtain review approval
8. Merge into `main`

---

## Main Branch Protection Rules

The `main` branch is protected and:

- Only reviewed content can be merged
- Pull Requests are required
- At least one approval is mandatory
- Direct pushes are disabled
